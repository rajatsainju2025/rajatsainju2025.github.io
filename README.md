# rajatsainju2025.github.io

Source for my personal website, served by GitHub Pages at
https://rajatsainju2025.github.io.

It is a plain static site: no framework and no build step.

## Editing

All content is in [`assets/js/data.js`](assets/js/data.js):

- `SITE`: name, title, bio, email, location, CV and social links. An empty
  string hides that item.
- `NEWS`: the scrolling news cards, newest first. Each card uses an `image`,
  or an `emoji` with a `tint` (violet, amber, teal, rose, sky, slate, lime).
- `PROJECTS`: papers, each with a thumbnail `image` (and a full `figure`
  shown on click) or a text `card`, a TLDR and links. `s2` is the Semantic
  Scholar paper ID or `DOI:...` used for the live citation count. Papers whose
  `venue` starts with "Microscopy & Microanalysis", "NAPAC" or "IPAC" go to
  Conference Papers; the newest 3 are shown and the rest sit behind
  "Show all" (change `MM_SHOWN` or `isMM` in `main.js`). Everything else is
  listed under Publications; add `more: true` to a paper to list it only
  after "Show all".
- `ABSTRACTS`: extra conference abstracts without a figure, shown under
  "Show all".
- `SOFTWARE`: repository cards. Stars and forks are fetched live from GitHub.

After editing, run the prerender step, then push to `main`. The site updates
within a minute or two.

```bash
pip install playwright      # once
python tools/prerender.py
```

The prerender step saves the rendered page into `index.html`, so all content is
plain HTML that search engines can read without running JavaScript. It also
updates the `?v=` cache-busting tags and the date in `sitemap.xml`. If you
forget it, visitors still see the new content (main.js renders from
`data.js`), but search engines see the old HTML until the next run.

## Previewing locally

```bash
python -m http.server 8000
# then open http://localhost:8000
```

## Layout

```
index.html            page (prerendered from data.js by tools/prerender.py)
robots.txt, sitemap.xml
assets/css/style.css  styles
assets/js/data.js     content
assets/js/main.js     renders the content
assets/img/           thumbnails (figures from the papers)
```

The layout is modelled on [mattdeitke.com](https://mattdeitke.com/) and was
written from scratch. Project figures are reproduced from the papers listed,
with each figure linked to its publication. The news illustrations are
generated by `tools/news_art.py`.

## Search

- `<head>` in `index.html` has the page title, description and a schema.org
  `Person` block (JSON-LD) that links the GitHub, LinkedIn and Google Scholar
  profiles. Edit it by hand; the prerender step keeps it as is.
- `robots.txt` and `sitemap.xml` sit at the root. The sitemap is submitted in
  Google Search Console.
